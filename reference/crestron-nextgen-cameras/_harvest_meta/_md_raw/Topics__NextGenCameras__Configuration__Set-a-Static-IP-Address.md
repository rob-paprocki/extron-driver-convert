## Set a Static IP Address

Crestron 1 Beyond cameras ship with DHCP turned on by default. The camera should be set to a static IP address for communications over the network.

To set a static IP address for a camera:

1.  Select **Settings** on the desired camera in the camera list to open the **Advanced Settings** menu.
    
    Settings Select
    
    ![](../../../Resources/Images/1BCameraManager/Camera Manager Screenshots/AdvancedSettingsSelect.png)
    
    The **Advanced Settings** menu is displayed.
    
    Advanced Settings Menu
    
    ![](../../../Resources/Images/1BCameraManager/Camera Manager Screenshots/Advanced Settings/Protocol.png)
    
2.  Select the **Network** tab on the top of the **Advanced Settings** menu to access the **Network** menu.
    
    Network Menu
    
    ![](../../../Resources/Images/1BCameraManager/Camera Manager Screenshots/Advanced Settings/Network.png)
    
3.  Select the **IP Type** drop-down menu, then select **Static IP**.
    
4.  Use the **IP Address** text field to enter a static IP address for the camera.
    
5.  Select **Save Settings** to save the static IP address for the camera.
    

The camera is now set to a static IP address.

note: Cameras can also be set to a static IP address in the **ADD CAMERA** window. For more information on setting a static IP via the **ADD CAMERA** window, refer to [Edit IP](Add-Cameras.htm#EditIP)
