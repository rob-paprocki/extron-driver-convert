# PW-1225DU Features

The [PW-1225DU](https://www.crestron.com/model/6513216 "https://www.crestron.com/model/6513216") is a 12 VDC universal regulated power pack intended for use with Crestron 1 Beyond [IV‑CAM‑P20](https://www.crestron.com/model/6513205 "https://www.crestron.com/model/6513205"), [IV‑CAM‑P12](https://www.crestron.com/model/6513209 "https://www.crestron.com/model/6513209"), [IV‑CAM‑I20](https://www.crestron.com/model/6513200 "https://www.crestron.com/model/6513200"), and [IV‑CAM‑I12‑B](https://www.crestron.com/model/6513204 "https://www.crestron.com/model/6513204") cameras.
