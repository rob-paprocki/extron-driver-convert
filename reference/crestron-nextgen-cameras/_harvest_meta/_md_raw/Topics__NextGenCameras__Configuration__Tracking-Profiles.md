## Zone Profiles

note: This feature is only available with IV-CAM-I20 series cameras.

Zone profiles allow IV-CAM-I20 series cameras to switch between up to four different intelligent zone configurations. This feature is useful for when an IV-CAM-I20 camera is used in a multi-purpose space where Tracking Zones, Blocking Zones, and Preset Zones configurations are required for different areas.

Complete the following procedure to configure Zone Profiles:

1.  Select the **Tracking** button on the desired camera in the Camera List.
    
    Tracking Button
    
    ![](../../../Resources/Images/1BCameraManager/Camera Manager Screenshots/AccessTrackingSettings.png)
    
    The Tracking Menu is displayed.
    
    Tracking Menu
    
    ![](../../../Resources/Images/Camera_Manager_8-26-25/TrackingZones_Menu_i20_82625.png)
    
2.  At the bottom of the **Tracking Zones** tab, select one of the following **Zone Profiles**:
    
    Zone Profiles
    
    ![](../../../Resources/Images/Camera_Manager_8-26-25/TrackingZones_ZoneProfiles_Highlighted_82625.png)
    
    Zone Profile Selections
    
     
    
    Zone Profile Designation
    
    Tracking Zone Profile Configuration
    
    Z1
    
    Tracking Zone Profile 1 (default Tracking Profile)
    
    Z2
    
    Tracking Zone Profile 2
    
    Z3
    
    Tracking Zone Profile 3
    
    Z4
    
    Tracking Zone Profile 4
    
    When the Zone Profile is selected, the i20 camera switches to its configured intelligent features (Tracking Zone, Blocking Zones, Preset Zones, **Home Shot** (**Preset 0**), and **Tracking Shot** (**Preset 1**). If they have not been configured yet, proceed to step 3.
    
3.  Configure the intelligent features for the selected Zone Profile. For more information on configuring the intelligent features, refer to [Tracking Menu](Intelligent-Settings.htm)
    

The Tracking Profile is now configured. Repeat the above procedure for any additional Zone Profile requirements.

tip: During camera operation, a reserved camera preset can be called to switch the Zone Profile. Refer to the following table for reserved Zone Profile presets:
