# Update Firmware

Once the Crestron 1 Beyond camera is added to the Crestron 1 Beyond Camera Manager 2 software, the camera should be updated to the latest firmware. For more information on adding a camera to the software, refer to [Add Cameras](Add-Cameras.htm).

To update the firmware of the camera:

1.  Select **Settings** on the desired camera in the camera list to open the **Advanced Settings** menu.
    
    Settings Select
    
    ![](../../../Resources/Images/1BCameraManager/Camera Manager Screenshots/AdvancedSettingsSelect.png)
    
    The **Advanced Settings** menu is displayed.
    
    Advanced Settings Menu
    
    ![](../../../Resources/Images/1BCameraManager/Camera Manager Screenshots/Advanced Settings/Protocol.png)
    
2.  Select **Upgrade** on the top of the **Advanced Settings** menu to access the **Upgrade** menu.
    
    Upgrade Menu
    
    ![](../../../Resources/Images/1BCameraManager/Camera Manager Screenshots/Advanced Settings/Upgrade.png)
    
3.  Download the respective camera firmware package from the [Crestron website](https://www.crestron.com/Support/Search-Results?c=4&m=10&q=IV-CAM&o=0 "https://www.crestron.com/Support/Search-Results?c=4&m=10&q=IV-CAM&o=0").
    
4.  Select the three dots icon on the right of the **Firmware** field. This opens a file explorer window on the computer.
    
5.  Navigate to the firmware file on the computer. Select the firmware file and the camera then performs the firmware update.
    
    note: The firmware file must be extracted from the downloaded .zip file before updating the camera. Failure to do so causes the firmware file to not be discoverable by the software.
    
6.  The firmware update status is displayed next to **Upgrade Status**. Wait for the **Upgrade Status** to display **Completed** before leaving this menu. Once **Completed** is shown, the firmware update is complete.
    

The camera is now updated to the latest firmware. To enable automatic updates for the camera, refer to [Network Settings](Advanced-Settings.htm#Network).
