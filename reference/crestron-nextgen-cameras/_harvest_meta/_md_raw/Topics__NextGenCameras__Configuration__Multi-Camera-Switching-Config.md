# Intelligent Switching

Intelligent Switching utilizes up to five Crestron 1 Beyond cameras to switch between Group Framing, Presenter Tracking, and static camera shots. This is achieved by having a host camera (IV-CAM-I12 set to Group Framing or IV-CAM-I12D-B), alongside additional cameras connected on the network.
