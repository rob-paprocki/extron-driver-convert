# IV-CAMA-REMOTE Features

The [IV‑CAMA‑REMOTE](https://www.crestron.com/model/6513217 "https://www.crestron.com/model/6513217") is an IR wireless remote designed to be used with [IV‑CAM‑I12‑B](https://www.crestron.com/model/6513204 "https://www.crestron.com/model/6513204") cameras. The IV‑CAMA‑REMOTE provides full access to camera video settings, calling predefined camera presets, and enabling or disabling camera tracking.
