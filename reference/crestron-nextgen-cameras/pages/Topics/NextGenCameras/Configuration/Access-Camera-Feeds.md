# Accessing Camera Feeds

Both the main PTZ camera and wide-angle reference camera video feeds can be displayed in the user interface at the same time. Up to four different video feeds from other cameras can be displayed. Refer to the following sections for more information on accessing and viewing camera video feeds.

## View the PTZ Camera Feed

To view the PTZ camera's video feed, select **Main** on the desired camera in the camera list.

Main Video Feed

![](../../../Resources/Images/1BCameraManager/Camera Manager Screenshots/SelectMain.png)

The main PTZ camera's feed is now displayed in the user interface.

Main Stream View

![](../../../Resources/Images/1BCameraManager/Camera Manager Screenshots/MainSteamDisplayed.png)

note: If four camera feeds are displayed in the quad view, adding a new feed from the camera menu will replace the last added feed. To control the camera feed that is replaced, left click on the feed in the quad view before selecting a new feed.

### View the PTZ 1 and PTZ 2 Camera Feeds (IV-CAM-I12D-B)

The IV-CAM-I12D-B has two PTZ cameras that are available to view. To view the PTZ camera video feeds, select **PTZ 1** or **PTZ 2** on the desired camera in the camera list.

PTZ 1 and PTZ 2 Feeds

![](../../../Resources/Images/1BCameraManager/Camera Manager Screenshots/i12D/PTZ1PTZ2.png)

The selected PTZ camera's feed is now displayed in the user interface.

### View the Output (IV-CAM-I12D-B)

The IV-CAM-I12D-B switches between its PTZ 1, PTZ 2, and reference camera video feeds during operation. To view the current output of the IV-CAM-I12D-B, select **Output** on the desired camera in the camera list.

note: Conversation Mode and Picture-in-Picture (PIP) layouts are not visible on the Output via Camera Manager. These layouts are only available on the HDMI and USB streams of the camera. For more information about layouts, refer to [Speaker Tracking Settings](Speaker-Tracking-Settings.htm).

Output Feed

![](../../../Resources/Images/1BCameraManager/Camera Manager Screenshots/i12D/Output.png)

## View the Wide-Angle Reference Camera Feed

To view the wide-angle reference camera's video feed, select **Reference** on the desired camera in the camera list.

Reference Video Feed

![](../../../Resources/Images/1BCameraManager/Camera Manager Screenshots/SelectReference.png)

The wide-angle reference camera's feed is now displayed in the user interface.

Wide-Angle Reference Stream

![](../../../Resources/Images/1BCameraManager/Camera Manager Screenshots/ReferenceStreamDisplayed.png)

note: If four camera feeds are displayed in the quad view, adding a new feed from the camera menu will replace the last added feed. To control the camera feed that is replaced, left click on the feed in the quad view before selecting a new feed

## Closing Camera Feeds

To close a camera's video feed, right click the desired video feed and select **Close Stream**.

Close Stream

![](../../../Resources/Images/1BCameraManager/Camera Manager Screenshots/Stream Quad-View Right Click.png)

NOTE: The procedure above works on both the quad view and full screen video feeds.

Full Screen Close Stream

![](../../../Resources/Images/1BCameraManager/Camera Manager Screenshots/Stream Expanded Right Click.png)

Alternatively, selecting the **Main** or **Reference** buttons closes the respective camera's video feed.

## View the Full Screen Camera Feed

By default, the quad view is displayed in the user interface. To view a camera's video feed in full screen instead of quad view, select the double arrow icon in the top right corner of the respective video feed.

Double Arrow Icon

![](../../../Resources/Images/Stream Quad-View Full Screen Arrow.png)

Alternatively, right click the desired video feed and select **Full-Screen Stream** to enter full screen borderless mode, hiding the user interface. Right click and select **Close Stream** to exit the full screen borderless mode.

Select Full-Screen Stream

![](../../../Resources/Images/Stream Quad-View Right Click Full Screen.png)
