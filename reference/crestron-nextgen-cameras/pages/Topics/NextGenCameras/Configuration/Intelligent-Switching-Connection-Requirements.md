# Connection Requirements

Before proceeding to the desired Intelligent Switching configuration, observe the following connection requirements for **Intelligent Switching**:

*   All cameras that are used must be connected on the same network via an Ethernet cable.
    
*   The host camera (IV-CAM-I12 set to Group Framing or IV-CAM-I12D-B) must be connected via USB into a conferencing codec such as a [Crestron Collab Compute](https://www.crestron.com/model/6514436 "https://www.crestron.com/model/6514436").
    
    *   The conferencing codec must be operating with a software compatible with MJPEG camera output.
        
*   A laptop docking station cannot be used for video output.
    
*   Intelligent Switching is not compatible with the SDI and HDMI video outputs.
