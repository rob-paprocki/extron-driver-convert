# Intelligent Switching Design

There are two configurations available for Intelligent Switching, both providing a different camera switching experience. Additionally, both of the configurations require different cameras, connection methods, and hardware.

Refer to the following sections for more information on the available Intelligent Switching configurations.

## Visual Cue Intelligent Switching

Visual Cue Intelligent Switching utilizes an IV‑CAM‑I12 camera in Group Framing mode and up to four other Crestron intelligent cameras (IV-CAM-I12 and IV-CAM-I20 models) serving as Presenter Tracking cameras.

This configuration only requires the Crestron 1 Beyond Camera Manager 2 software for initial setup. For more information on this configuration, refer to [Visual Cue Intelligent Switching Configuration](Visual-Cue-Intelligent-Switching-Config.htm).

## Custom Intelligent Switching

Custom Intelligent Switching utilizes an IV‑CAM‑I12 camera in Group Framing mode and up to four other Crestron 1 Beyond cameras (IV-CAM-P12/P20 models and IV-CAM-I12/I20 models).

This configuration requires the provided example module located on the respective camera product page and a control system. For more information on this configuration, refer to [Custom Intelligent Switching Configuration](Custom-Intelligent-Switching-Config.htm).
