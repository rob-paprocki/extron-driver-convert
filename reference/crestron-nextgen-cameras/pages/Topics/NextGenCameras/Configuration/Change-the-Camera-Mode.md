# Change the Camera Mode

IV-CAM-I12 and IV-CAM-I12D-B cameras can be set to their desired intelligent camera mode, and should be set once the camera is added to the Crestron 1 Beyond Camera Manager 2 software. For more information on adding a camera to the software, refer to [Add Cameras](Add-Cameras.htm).

To change the camera mode:

1.  Select the **Tracking** button in the camera list.
    
    Tracking Button
    
    ![](../../../Resources/Images/1BCameraManager/Camera Manager Screenshots/AccessTrackingSettings.png)
    
    The Tracking Menu is displayed.
    
    Tracking Menu
    
    ![](../../../Resources/Images/1BCameraManager/Camera Manager Screenshots/Tracking Settings i20/TrackingMenui20.png)
    
2.  Select the **Tracking Settings** tab.
    
    Select Tracking Settings
    
    ![](../../../Resources/Images/1BCameraManager/Camera Manager Screenshots/SelectTrackingSettings.png)
    
    The **Tracking Settings** menu is displayed.
    
    Tracking Settings Menu
    
    ![](../../../Resources/Images/Camera_Manager_8-26-25/TrackingSettings_MultiCam_82625.png)
    
3.  Select the button at the top of the Tracking Settings tab. Depending on the camera mode, it displays either **Switch to Presenter Tracking** or **Switch to Group Framing**.
    
    note: The image below displays the i12 camera in Group Framing mode.
    
    Switch to Presenter Tracking
    
    ![](../../../Resources/Images/Camera_Manager_8-26-25/TrackingSettings_SwitchtoPresenter_82625.png)
    

The camera is now set to the desired camera mode.
