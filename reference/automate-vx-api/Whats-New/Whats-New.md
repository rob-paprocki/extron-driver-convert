# What's New?

Updates to the Automate VX API and this documentation are described below from newest to oldest.

* * *

## July 1, 2025

*   **Documentation Updates for Automate VX firmware release 6.4.2**
    *   Updated all topics to change the API calls to reflect port 4443 in the base URLs.

* * *

## May 9, 2025

*   **API Documentation Updates for Automate VX firmware release 6.4.1**
    *   Removed support for depreciated CallPlugin API call.

* * *

## August 15, 2024

*   **API Documentation Updates for Automate VX firmware release 6.3**
    *   Added support for [GetActiveTalkers API](../API-Reference/GetActiveTalkers-API.htm) call.

* * *

## December 28, 2023

*   **Documentation Updates**
    *   Updated the following topics to change the supported camera ID values from \[1–8\] to \[1–255\]: [CallCameraPreset API](../API-Reference/CallCameraPreset-API.htm), [CameraStatus API](../API-Reference/CameraStatus-API.htm), [GetCameras API](../API-Reference/GetCameras-API.htm), [ManualSwitchCamera API](../API-Reference/ManualSwitchCamera-API.htm), [SaveCameraPreset API](../API-Reference/SaveCameraPreset-API.htm), [StartPT API](../API-Reference/StartPT-API.htm), [StartZ API](../API-Reference/StartZ-API.htm), [StopPT API](../API-Reference/StopPT-API.htm), [StopZ API](../API-Reference/StopZ-API.htm)

* * *

## September 8, 2023

*   **Documentation Updates**
    *   Updated cURL base and example commands for all API calls to fix syntax issues that were causing commands to not work properly.

* * *

## January 9, 2023

*   **API Documentation Updates for Automate VX firmware release 5.8**
    *   Added support for [GetAllStatus API](../API-Reference/GetAllStatus-API.htm), [GetScenarios API](../API-Reference/GetScenarios-API.htm), [GoToScenario API](../API-Reference/GoToScenario-API.htm), [Macro API](../API-Reference/Macro-API.htm), [Restart API](../API-Reference/Restart-API.htm), [ScenarioStatus API](../API-Reference/ScenarioStatus-API.htm), [SaveCameraPreset API](../API-Reference/SaveCameraPreset-API.htm), [ShotStatus API](../API-Reference/ShotStatus-API.htm), [StartPT API](../API-Reference/StartPT-API.htm), [StartZ API](../API-Reference/StartZ-API.htm), [StopPT API](../API-Reference/StopPT-API.htm), and [StopZ API](../API-Reference/StopZ-API.htm) calls.
    *   Updated [GetCameras API](../API-Reference/GetCameras-API.htm) call.

* * *

## January 5, 2023

*   **Documentation Updates**
    *   Updated [Authentication](../Quick-Start/Authentication.htm) and [Get-Token API](../API-Reference/Get-Token-API.htm) to show the correct base URI for the Get-Token API call.

* * *

## August 18, 2022

*   **Documentation Updates**
    *   Corrected all "HTTPS" references to "HTTP"

* * *

## August 15, 2022

*   **Initial Public Release**
    *   Initial release of Automate VX API documentation
