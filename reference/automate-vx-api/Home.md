# API for 1 Beyond Automate VX Series

The 1 Beyond Automate VX series provides voice-activated camera switching solutions that bring a full multicamera studio experience to meetings, town halls, and classrooms. Camera switching and movement are done automatically based on the active speaking participant. Automate VX comes with built-in recording and streaming capability along with outputs for video conferencing.

This documentation describes the API for the Automate VX server. The API allows programmers to modify device settings and view device status using API calls.

NOTE: This document is current as of the 6.4.1.8 firmware release.
