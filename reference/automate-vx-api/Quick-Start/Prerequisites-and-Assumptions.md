# Prerequisites and Assumptions

This document assumes the following knowledge prerequisites prior to working with the Automate VX API:

*   The programmer has a working knowledge of API programming conventions, including how to format HTTP requests to transfer data to and from the server.
*   The programmer has a working knowledge of 1 Beyond camera configuration and Automate VX system infrastructures and protocols.
*   The Automate VX system has been installed and is running on the network. For more information, refer to the appropriate [Automate VX documentation](https://www.crestron.com/support/search-results?c=6&m=10&q=iv-sam "https://www.crestron.com/support/search-results?c=6&m=10&q=iv-sam").
