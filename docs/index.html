Extron Driver Convert

Research into converting audio-visual device drivers between vendor formats: Extron .pkp (Global Configurator), Extron ControlScript .py, Crestron .pkg, Q-SYS plugins, Biamp Tesira.

Vendors ship different driver formats for the same devices, so the processor you own may not be able to control the device you own. If translation works, one driver can serve any processor. The repo contains working tools, measurements, and a growing corpus of findings on how far that goes in practice.

Research artifact, not a product. All tools are standard-library Python 3. Vendor material is not redistributed; the public copy of this repo omits every byte of it.

The four conversion directions

Extron .pkp → ControlScript
Done, measured. Translator with counted residuals; wire-string parity against the shipped module.
convert.py pkp2cs
ControlScript → Extron .pkp
Done via donor-transplant. Format and command surface both proven; the guide walks the i20 end-to-end.
convert.py cs2pkp
Crestron .pkg → ControlScript
pkg_dump measured. The finish from the driver JSON to a working module is a manual step.
convert.py pkg2cs
Extron → Crestron .pkg
Patch-only resource swap, mechanically demonstrated. Full emit is gated by the Crestron licence question (STATUS.md D2).
