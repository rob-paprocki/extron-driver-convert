# Pack-up, 2026-09

**This is history, not current state.** It records one workstation being
retired in September 2026 and its project files being moved into this repo. It
is kept because the "moved from → moved to" mapping explains why some
directories exist and where their contents came from. Nothing here describes
how to work on the project today — for that see `ENVIRONMENT.md`.

Read it only if you are asking "where did this directory come from?".

## What moved into `private/` (git-ignored, never pushed)

Claude Code transcripts and job records for the project; the Extron, Crestron
and ControlScript application settings; and the editor settings. The Extron
config carries licence blobs and a login email, and the transcripts carry full
tool output, account details and lab IPs, which is why none of it is in git.

The one project-relevant value inside it: the editor's
`"controlscript.version": "1.11.1xi"` — the ControlScript API level the
generated modules targeted.

## What stayed behind

Installed applications (reinstallable, versions above), GUI Designer's 2.9 GB
template payload (0 of 6,551 files modified after installation), and everything
unrelated to this project.

## Notes that were specific to that machine

Both of these are recorded because they cost time there, not because they are
general truths — see the troubleshooting section of `ENVIRONMENT.md` for the
conditional form:

- Git Credential Manager hung on an invisible prompt and, once killed, had no
  cached credential, so pushes went through `GIT_ASKPASS`. **This has since been
  observed not to reproduce elsewhere**; plain git auth can work without any of
  it.
- Git refused the network share as "dubious ownership" until the repo was added
  to `safe.directory`. This only ever applies to a checkout on a share.
