# evidence/

Raw artefacts from the hardware and Global Configurator runs that the findings
cite. Nothing in this folder is generated by the repo's tools, so if it is lost
it cannot be rebuilt.

Global Configurator's own catalogue data is Extron's, so `catalogue-snapshots/`
and `uploads/` are not included; `vendor-files.manifest.tsv` pins them.

## catalogue-snapshots/

GC's two catalogue files, captured around the 2026-09-10 GCP runs. GC truncates
both before rebuilding, so these were taken as backups and kept as evidence.

| file | captured |
|---|---|
| `DataFile.2026-09-09T2359.dat`, `DriverLookup.2026-09-09T2359.dat` | just before the corrected 20024 was installed |
| `DataFile.2026-09-10-pre-launch.dat` | just before GCP was launched by automation |

`DataFile` grew by 5,716 bytes between the first and second: the cost of
cataloguing `1bynd_19_20024`. Both files are raw NRBF, read them with
`tools/gc_catalogue.py`.
